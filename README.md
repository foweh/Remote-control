# mouse-ctrl-v3 🖱️📱

手机扫码控制电脑鼠标，局域网内毫秒级延迟。零 npm 依赖，双击即用。

## 快速开始

1. 双击 `start.bat`（或命令行 `node server.js`）
2. PC 页面自动打开，显示两张二维码
3. 手机连同一个 WiFi，扫二维码即可控制

> 二维码里编码的是**本机真实局域网 IP:端口**（如 `http://192.168.20.62:8642/...`），
> 电脑换 WiFi 后刷新页面二维码会自动更新。多网卡时页面下方可手动切换 IP。
> 首次运行 start.bat 会自动添加 Windows 防火墙放行规则（弹一次 UAC，点"是"），
> 之后手机才能访问到电脑；规则只需添加一次。

| 二维码 | 页面 | 功能 |
| --- | --- | --- |
| 🎮 触摸板控制 | `/control.html` | 移动鼠标、左/右键、滚轮、键盘输入、拖动锁 |
| 🔼🔽 滚轮遥控 | `/scroll.html` | 只有上下两个箭头，按住连续丝滑滚动，速度可调 |

## 滚轮遥控页（按住 = 滚动，松手 = 停）

- **上半屏 = 上滚，下半屏 = 下滚**，整屏都是触控区，不用找按钮
- 按住：像鼠标滚轮一样连续滚动；**400ms 缓动加速进入、100ms 渐停**，手感温柔丝滑
- 按住时手指滑到另一半屏幕，滚动方向自动切换
- 滚动循环在电脑端运行（手机只发"开始/停止"两条消息），网络抖动不影响流畅度，切后台/锁屏自动停止
- 底部速度滑块（1-10 档）实时可调，滚动途中调整立即生效；滚轮步幅已细化为 1/4 格

## 触摸板手势

| 手势 | 效果 |
| --- | --- |
| 单指滑动 | 移动鼠标（绝对模式：指哪打哪，按屏幕宽高比映射） |
| 单击 | 左键 |
| 双指点击 | 右键 |
| 双指上下滑 | 滚轮 |
| 拖动锁（按钮） | 点一下按住左键，再点一下松开 |
| 相对模式（按钮） | 像真实触摸板：滑动 = 相对位移，灵敏度可调 |
| ⌨️ 键盘 | 输入文字发送到电脑（中文走剪贴板粘贴） |

## 延迟为什么低

- 手机 → 电脑：WebSocket 直连推送，无轮询（局域网 RTT ≈ 1ms）
- 鼠标执行：常驻 PowerShell 进程 + P/Invoke（`SetCursorPos` / `mouse_event`），单条指令约 0.5ms
- 全链路延迟在手机页面实时显示（ping 穿过服务器和鼠标驱动再返回）
- 无任何 npm 依赖：HTTP 用 Node 内置模块，WebSocket 手写 RFC6455，二维码用本地 qrcodejs

## 文件说明

```
server.js          # 服务端：静态页 + WebSocket + 鼠标驱动桥 + 滚轮缓动循环
mouse.ps1          # 鼠标驱动（常驻进程，文本协议走 stdin）
start.bat          # 一键启动
public/
├── index.html     # PC 页面：双二维码 + IP 切换 + 连接状态
├── control.html   # 手机触摸板
├── scroll.html    # 手机双箭头滚轮遥控
└── qrcode.min.js  # 二维码库（本地，不走 CDN）
```

## 常见问题

- **手机打不开页面**：确认手机和电脑连的是同一个 WiFi/热点；Windows 防火墙首次弹窗请允许（专用网络）。
- **多网卡（虚拟网卡/虚拟机）IP 不对**：PC 页面上手动点正确的 IP 按钮，二维码会跟着变。
- **滚轮在个别老软件里没反应**：那些软件只认整格滚动，把速度调高即可。
- **中文输入**：键盘页面的中文通过剪贴板粘贴发送，发送期间电脑剪贴板会被短暂占用。
- **端口冲突**：`PORT=9000 node server.js` 换端口（手机端不用改，二维码自动带上）。
